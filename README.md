# GrievanceIQ - AI-Based Grievance Redressal System

An intelligent, full-stack grievance management and routing platform designed to streamline institutional complaint resolution workflows. 

##  Core Features
* **AI-Powered Routing:** Automatically classifies and routes incoming grievances across 7 institutional departments using Machine Learning text classification.
* **Secure Access Control:** Implemented role-based access control (RBAC) for students, department admins, and super admins, integrated with secure OTP-based email verification and comprehensive audit logging.
* **Lifecycle Tracking:** Provides full transparent tracking of grievances from initial submission to final resolution.

##  Tech Stack
* **Backend:** Python, Flask
* **Machine Learning:** Scikit-learn, Natural Language Processing (NLP)
* **Database:** SQLite3
* **Frontend:** HTML5, CSS3, JavaScript

##  Project Status
This repository represents an *ongoing* development phase. Core authentication, role management, and database tracking layers are implemented, with active iterations currently underway ML refinement modules and other features.
